# Personal Portfolio Website

A responsive personal portfolio website created with HTML, CSS, and JavaScript.

## Sections
- Home / introduction
- About me
- Skills
- Projects
- Education
- Contact links

## How to run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser, or use the Live Server extension in Visual Studio Code.

## Before publishing
- Confirm the name, course, and college details.
- Update the skills and projects to match your actual experience.
- Replace the LinkedIn and GitHub links with your own profile URLs.
- Replace `your.email@example.com` with the email address you want to publish, or remove that link.

## Technologies
- HTML5
- CSS3
- JavaScript
